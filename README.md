# IdeaNotes

把手写与语音快速变成可搜索的结构化笔记。

## 一句话
在画布上写、对着麦克风说，IdeaNotes 会把内容转成可检索文本，并进一步整理为“事项 / 花费 / 健康 / 备忘”等条目，方便回看与统计。

## 适用人群
- 喜欢用手写记录灵感、会议、学习笔记的人
- 想把零散记录快速变成“可搜索、可归档、可复用信息”的人

## 核心功能
### 1) 手写画布
- 自由书写与绘制
- 保存原始手写现场（便于回溯上下文与版式）

### 2) OCR 识别（手写 → 文本）
- 一键识别画布内容
- 识别结果可复制、可搜索、可分享

### 3) 语音转文字（语音 → 文本）
- 画布页一键开启语音输入
- 支持连续转写：多段语音会按段落自动追加，不会被下一句覆盖

### 4) 结构化整理
- 将识别文本进一步提取为结构化条目
- 在后续查询与统计中直接复用这些条目

### 5) 笔记管理与检索
- 笔记列表浏览
- 关键词搜索（标题与识别文本）

## 平台
